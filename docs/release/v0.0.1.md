# v0.0.1 · 首个发布

> STM32F103C8T6 健康监测小组项目的第一个可交付版本：**实物四路监测已跑通，Proteus 仿真可完整演示。**

## 这个版本有什么

| 能力 | 器件 | 状态 |
|---|---|---|
| 心率 / 血氧 | MAX30102（软件 I2C，Maxim 算法） | ✅ 实测心率 82–119 BPM、血氧 97–98% |
| 体温 | DS18B20（单总线 PA8，4.7 kΩ 上拉） | ✅ 实测 27 ℃ |
| 跌倒判定 | MPU6050（硬件 I2C2） | ✅ 87.7 Hz 判定，\|a\| 偏差 2.5 g 触发 |
| 显示 | 0.96" OLED SSD1306 | ✅ 四行中文界面，异常反色高亮 |
| 报警 | 有源蜂鸣器 PA12 | ✅ 跌倒长鸣 |
| 仿真 | Proteus + Wokwi | ✅ 显示 / 跌倒 / 蜂鸣器 / 温度跟随电位器 |

## 下载

| 文件 | 说明 |
|---|---|
| `SIT_health_monitor_real_v0.0.1.hex` | **实物固件**，烧录到 STM32F103C8T6（0x0800 0000） |
| `SIT_health_monitor_sim_v0.0.1.hex` | **仿真固件**，放入 `sim/proteus/IIC.hex` 供 Proteus 加载 |

两个 hex 都可用 Keil MDK 或 ST-Link/OpenOCD 烧录；源码分别在 `firmware/MAX30102/` 与
`firmware/MAX30102_sim/`。

## 快速开始

```bash
git clone git@github.com:PandaGuGu/stm32-health-monitor.git
cd stm32-health-monitor

# 实物固件（Keil）
powershell -ExecutionPolicy Bypass -File scripts/build.ps1

# 仿真固件（Keil 命令行），产物复制给 Proteus
"C:/Keil_v5/UV4/UV4.exe" -b "$PWD/firmware/MAX30102_sim/USER/IIC.uvprojx" -j0 -o build.log
cp firmware/MAX30102_sim/OBJ/IIC.hex sim/proteus/IIC.hex
```

打开 `sim/proteus/SIT_sim.pdsprj` 即可运行仿真；按 SW3 演示跌倒报警，
转 RV2 电位器演示温度变化。

## 已知限制

- 仿真里没有 MAX30102 / MPU6050 模型，DS18B20 加载的是 `DS1822.MDF`（命令写不进），
  所以**温度用 RV2 电位器模拟、心率用固件节律**；实物的这两项仍是真传感器。
- Proteus MCU 模型 `CLOCK_SCALE=8`（≈64 MHz）与固件假设的 72 MHz 差 12.5%，
  把 `Clock Scale` 改成 `9 Times` 可消除。
- 本项目为课程/学习性质，**不是医疗器械**；算法与阈值未经临床验证。
