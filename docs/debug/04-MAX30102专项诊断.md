## 二、四项独立测量（互相印证）

### ① MCU 引脚本身是好的 —— 排除「引脚损坏」

```
pin_hi[8] 驱动推挽高后回读 = 1 1 1 1 1 1 1 1   全部正确
pin_lo[8] 驱动推挽低后回读 = 0 0 0 0 0 0 0 0   全部正确
           (0=PA5 1=PA6 2=PA8 3=PA12 4=PB7 5=PB8 6=PB10 7=PB11)
```

**PB7 和 PB8 的驱动能力、回读能力都正常**，没有被短路到 GND/VCC，也不是坏脚。

### ② 上下拉探测 —— 无外部上拉

```
bus_pd[5] (IPD 读，1=有外部上拉) = 0 0 1 1 1
                                   ↑ ↑ └─ PB10,PB11,PA8 = 1 ✅ 有器件
                                 PB7,PB8 = 0        ❌ 无上拉
bus_pu[5] (IPU 读，0=被拉低)     = 1 1 1 1 1   → 没有任何线被拉死
```

判读：PB7/PB8 = **FLOATING（悬空，无上拉）**。

### ③ 全引脚上拉普查 —— 全板只有 5 根针有器件

```
PA 外部上拉掩码 = 0x1160  →  PA5, PA6, PA8, PA12       （OLED / DS18B20 / 板载USB）
PB 外部上拉掩码 = 0x0C00  →  PB10, PB11                （MPU6050）
被拉低掩码      = 0x0000 / 0x0000
```

**MAX30102 模块自带的 4.7 kΩ 上拉（GY 模块都有）在整块板子上一个都没出现。**
→ 如果模块接着并且有电，它的上拉必然出现在某两根针上。没有。

### ④ RC 电容探针 —— 连导线的分布电容都没有

```
PB[0..15] = 2  2  2  3392  0  2  2  [3]  [3]  [3]  0   0   2  2  2  2
                                    PB7  PB8  PB9  PB10 PB11
                                     └─ 3 = 裸脚 ─┘  └ 0 = MPU ✅ ─┘
```

**校准参照（板载走线）：**

| 引脚 | 读数 | 含义 |
|---|---|---|
| PA0 | 2 | 短裸脚 |
| **PA11** | **3** | 仅一条 PCB 走线连到 USB 座，**无导线** |
| PA12 | 0 | 板载 1.5 kΩ 上拉 |
| PB10 / PB11 | 0 | 挂了 MPU6050（有供电器件） |
| **PB7 / PB8 / PB9** | **3** | **= PA11 级别，即"只有 PCB 走线，没有导线"** |

一根 20 cm 杜邦线的分布电容约 20~40 pF，会让读数升到 **12 以上**。现在读 3。

## 四、为什么「检查接线」没解决问题

「看起来插上了」和「电气上接通了」是两件事。以下四种情况，**肉眼看外观完全一样**，但电气上都等于"没接"：

| 情况 | 说明 |
|---|---|
| **面包板孔内弹片失效** | 廉价面包板某列弹片氧化/变形，插进去但接触电阻无穷大。**换一列插即可验证。** |
| **杜邦线内部断芯** | 线皮完好，铜丝已断。**必须用万用表通断档量，看不出来。** |
| **插在相邻一列** | 面包板孔距 2.54 mm，差一列视觉上几乎看不出来 |
| **MCU 排针没插进面包板** | 板子架在面包板上但排针悬空 |

## 五、请按顺序做（第 1、2 条最关键）

### 1️⃣ 万用表通断档 —— 不看外观，只听响

```
MAX30102 的 SCL 线：一端(模块侧) ↔ 另一端(MCU PB7 排针)   必须蜂鸣
MAX30102 的 SDA 线：一端(模块侧) ↔ 另一端(MCU PB8 排针)   必须蜂鸣
MAX30102 的 VCC 线：一端(模块侧) ↔ 另一端(3.3V 轨)        必须蜂鸣
MAX30102 的 GND 线：一端(模块侧) ↔ 另一端(GND 轨)         必须蜂鸣
```

**线在手上量（拔下来量），排除面包板的干扰。**

### 2️⃣ 看模块上那颗红色电源 LED

GY-MAX30102 板载一颗电源指示灯。**亮 = 供电通；不亮 = VCC/GND 没通。**

### 3️⃣ 脱离面包板，4 根杜邦线直连

把 MAX30102 从面包板上拔下来，用 4 根线**直接插到 MCU 的排针上**：

| MAX30102 | MCU |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCL | **PB7** |
| SDA | **PB8** |

这一步同时排除「面包板弹片失效」和「插错列」。

### 4️⃣ 隔离测试：把 SCL/SDA 挪到 PB10 / PB11

这是**判定模块本身好坏**的终极手段 —— 挪到 MPU6050 已验证可用的那条总线：

| MAX30102 | 改接 |
|---|---|
| SCL | **PB10** |
| SDA | **PB11** |

**看 OLED 第 2 行（固件每 3 秒自动刷新）：**

- 出现 **`M2OK`** → **模块是好的**，问题 100% 在 PB7/PB8 的线/排针/面包板
- 仍是 **`M2--`** → **模块本身没供电或已损坏**

## 六、OLED 实时显示（阅读方法）

```
DIAGLIVE 099          ← 循环计数，在跳 = 固件活着
M1-- M2-- ack0        ← M1=PB7/PB8 结果, M2=PB10/PB11 结果, ack=应答个数
MPU. 68 DS. 110       ← MPU/DS 状态
P7=3  P8=3  P9=3  A8=0     ← 裸脚=2~3，接好=0，只挂线不供电=10+
A5=0  A6=0  B10=0 B11=0    ← 对照组（这四根确实接好了）
```

**第 5 行是标准答案**：`A5/A6/B10/B11` 全 0。第 4 行如果也变成全 0，就是接好了。
