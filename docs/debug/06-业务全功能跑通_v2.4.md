## 三、可复现的交底

### 接线（与 sensor 丝印一一对应）

| 模块 | 引脚 |
|---|---|
| MAX30102 | VCC→3.3V，GND→GND，SCL→PB7，SDA→PB8，INT→PB9 |
| OLED | VCC→3.3V，GND→GND，SCK→PA5，SDA→PA6 |
| MPU6050 | VCC→3.3V，GND→GND，SCL→PB10，SDA→PB11 |
| DS18B20 | VCC→3.3V，GND→GND，DQ→PA8 |
| 蜂鸣器 | VCC→3.3V，GND→GND，I/O→PA12 |

### 构建与烧录

```bash
cd firmware/MAX30102/gcc
make APP=1            # 完整业务固件（含 MAX30102）
make APP=1 flash      # 编译 + OpenOCD 烧录
make APP=1 NOMAX=1    # 需要时：无 30102 关闭版
```

## 四、遗留与建议

1. **`max30102_init()` 里的 LED 电流是 7mA**（`LED1_PA=LED2_PA=0x24`）。若实测波形
   幅度偏小、心率不稳，可提高到 `0x3F`（约 12mA）或 `0x5F`（约 18mA）再试。
2. `algorithm.c` 有两条 `-Wmaybe-uninitialized` 警告（原工程既有），本轮未动。
3. `ds18b20.c` 的 `ds18b20_rst()` 仍有两处无超时 while；业务固件走的是 `app_main.c`
   里的本地 timeout-safe 驱动，不调用它，故无影响。若将来改用 `ds18b20.c`，需先补超时。
