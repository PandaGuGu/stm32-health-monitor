## 二、关键改进：现在可以「边插边看」

固件已升级，**每 3 秒自动重跑一轮完整扫描**，所以：

> 你改一根线，OLED 上 3 秒内就会变。**不需要我再重新烧录。**

**引脚 RC 读数读法（重要）：**

| 引脚 RC 读数 | 含义 |
|---|---|
| **0** | 该线上挂着**有供电的器件**（器件的上拉把线瞬间拉高）—— 这是「接好了」 |
| **2~3** | **裸脚**（只有几 pF 的引脚电容）—— 没接线 |
| **>10** | 只接了线、但线的那头没有上拉（悬空的长线） |
