## 1. 全引脚 RC 电容计数（原始值）

紧循环计数法：引脚推挽拉低放电 → 切内部上拉（40 kΩ）→ 数多少圈才变高。
**裸引脚 ≈ 2**，挂了线/模块应变大。

```
PA0..PA15 = 2 2 2 2 2 2 2 2 2 2 2 2 | 0 0 0 0
PB0..PB15 = 2 2 2 3392 0 2 2 2 2 2 1 2 2 2 2 2
             ↑PB3        ↑PB4        ↑PB10
```

### 逐项判读

| 引脚 | 计数 | 判读 |
|---|---|---|
| **PA12** | **0** | 板载 USB_DP 的 **1.5 kΩ 上拉**死死拉高 → 内部下拉拉不动 → 立即读高 |
| **PB3** | **3392** | ⚠️ **假信号**。PB3 = JTDO，复位后由 JTAG 控制器接管，我写 `CRL` 不生效 → 计数是 JTAG 时序伪影，**不是线** |
| **PB4** | **0** | ⚠️ 同理，PB4 = NJTRST，JTAG 控制 → 伪影 |
| **PB10** | 1 | 与裸脚无实质差异 |
| 其余全部 | 2 | **= 裸引脚基线** |

**关键：`PA12 = 0` 是这台仪器的自校准点。** 板载那颗 1.5 kΩ 是真实存在的外部上拉，探针把它读成 0（区别于裸脚的 2）——**说明这个探针确实能分辨"有东西"和"没东西"。**

而 PB7 / PB8 / PB9 / PA5 / PA6 / PA8 / PB10 / PB11 —— **全部 = 2 或 1，与裸脚基线一致。**

## 2. 上拉普查（交叉验证，结论一致）

方法：引脚配成**内部下拉（40 kΩ）**，读 50 µs 后的电平。读到 1 = 存在外部上拉。

```
PA 外部上拉掩码 = 0x1000   (仅 PA12)
PB 外部上拉掩码 = 0x0000   (无)
PA 被拉低掩码   = 0x0000   (无)
PB 被拉低掩码   = 0x0000   (无)
```

**除 PA12 外，全板没有任何外部上拉。**

两颗传感器的模块通常都自带 4.7 kΩ 上拉（GY-521 的 SDA/SCL、GY-MAX30102 的 SCL/SDA/INT），DS18B20 更是**必须**外接 4.7 kΩ。**一个都没测到。**

## 4. 结论

**此刻，MCU 的任何传感器引脚上都没有建立电气连接。**

三条独立证据同向，且第一条是自校准过的：

1. **上拉普查**（用板载 PA12 的 1.5 kΩ 验证过方法有效）→ 除 PA12 外零外部上拉
2. **RC 电容探针**（同样用 PA12 自校准）→ 所有传感器引脚 = 裸脚基线 2
3. **通信扫描** → MAX30102 零 ACK、DS18B20 零应答

### 与历史事实的冲突（重要）

10-13 那次，**用户在 OLED 屏上亲眼读到 `DIAG RUN / MAX 00 / MPU 68 / DS NO`**——
说明当时 **OLED（PA5/PA6）和 MPU6050（PB10/PB11）确实是接好且工作的**（WHO_AM_I 返回真值 0x68）。

**而现在，正是这几根针（PA5/PA6、PB10/PB11）也退化成了裸脚读数。**

⟹ **在这一轮的插拔过程中，传感器的杜邦线从 MCU 排针上脱落了。**
（结合照片：用户把一个 2×5 的 IDC 大接头压在了 20 针 GPIO 排针上——那正好会把这些线挤掉。）

## 5. 顺带修正的两个文档/代码不一致

| 项 | 仓库文档 `board/schematic.md` | 实际代码 |
|---|---|---|
| MAX30102 INT | PB9 | **PB14**（`max30102.c:247`，`GPIOB` + `GPIO_Pin_14`，`IPU`） |

另：`myiic.h` 中 `SDA_IN()` 把 PB8 配成 **输入浮空**（CNF=01），不是上拉。
所以总线无外部上拉时，读 ACK 的电平是悬空的 —— 建议改成 `IPU`。

## 6. 建议的下一步

按性价比排序：

1. **拍一张照片**：MCU 板俯视，要看清**每一根杜邦线插在哪个针上**（连同排针丝印）。
2. **把 IDC 大接头从 20 针 GPIO 排针上拿开**，改用 4 根独立杜邦线接到复位键旁那个 **4 针 SWD 座**。
3. **重新插紧传感器线**，然后回一句，我立刻用 `adapter speed 20` 重连复测。
4. DS18B20 的 **4.7 kΩ 上拉**——用户此前说过"没有电阻"。驱动虽然用内部 40 kΩ 上拉兜底（`ds18b20.c:45` `GPIO_Mode_IPU`），但那是权宜之计，强烈建议补一颗。
