## 2. 全引脚 RC 电容计数（原始值）

紧循环计数法：引脚推挽拉低放电 → 切内部上拉（40 kΩ）→ 数多少圈才变高。
**裸引脚 ≈ 2**，挂了线/模块应变大。

```
PA0..PA15 = 2 2 2 2 2 2 2 2 2 2 2 2 | 0 0 0 0
PB0..PB15 = 2 2 2 3392 0 2 2 2 2 2 1 2 2 2 2 2
             ↑PB3        ↑PB4        ↑PB10
```

### 逐项判读

| 引脚 | 计数 | 判读 |
|---|---|---|
| **PA12** | **0** | 板载 USB_DP 的 **1.5 kΩ 上拉**死死拉高 → 内部下拉拉不动 → 立即读高 |
| **PB3** | **3392** | ⚠️ **假信号**。PB3 = JTDO，复位后由 JTAG 控制器接管，我写 `CRL` 不生效 → 计数是 JTAG 时序伪影，**不是线** |
| **PB4** | **0** | ⚠️ 同理，PB4 = NJTRST，JTAG 控制 → 伪影 |
| **PB10** | 1 | 与裸脚无实质差异 |
| 其余全部 | 2 | **= 裸引脚基线** |

**关键：`PA12 = 0` 是这台仪器的自校准点。** 板载那颗 1.5 kΩ 是真实存在的外部上拉，探针把它读成 0（区别于裸脚的 2）——**说明这个探针确实能分辨"有东西"和"没东西"。**

## 3. DS18B20 上拉建议

DS18B20 必须外接 **4.7 kΩ** 上拉。驱动虽然用内部 40 kΩ 上拉兜底（`ds18b20.c:45` `GPIO_Mode_IPU`），但那是权宜之计，强烈建议补一颗。

## 附：复现命令

```bash
T=$HOME/tools
$T/xpack-openocd-0.12.0-7/bin/openocd.exe \
  -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "adapter speed 20" -c "init" &

$T/xpack-arm-none-eabi-gcc-14.2.1-1.1/bin/arm-none-eabi-gdb.exe \
  $T/LIVE.elf -batch -x $T/dump_all.gdb
```

**注意：`adapter speed` 必须 ≤ 20，否则连不上。**
