# 10 · 仿真专用固件说明（v9）

> 这份固件**只用于 Proteus 仿真**，不是实物固件。
> 实物请继续用 `firmware/MAX30102/USER/main.c`（一行未改）。

## 1. 为什么需要一份单独的仿真固件

`SIT_sim.pdsprj` 里的器件与实物并不等价：

| 项 | 实物 | 仿真工程 | 后果 |
|---|---|---|---|
| MAX30102（心率血氧） | 有 | **没有这个器件** | 原固件会卡在 `while(MAX30102_INT==1)`，永远进不了主循环 |
| MPU6050（跌倒） | 有 | 没有 | 跌倒判定无数据源 |
| DS18B20（温度） | 有，工作正常 | 有符号，但加载的是 `DS1822.MDF` 模型 | 单总线命令写不进去，读回恒为 `0xFFFF` |
| STM32 主频模型 | 72 MHz | `CLOCK_SCALE = 8 Times`（≈64 MHz） | 所有延时偏慢约 12.5%，心率/周期类测量全部偏移 |

其中 DS18B20 一项做过 48 组时序组合的自动扫描（开漏/推挽 × 6 组时隙 × 2 种输入模式 ×
2 种命令重发），全部无法读出合法暂存器，判定为该模型无法与当前 MCU 模型通信。

## 2. 这一版的行为

| 功能 | 数据来源 | 说明 |
|---|---|---|
| 温度 | **RV2 电位器（首选）** | 抽头 → PA0(ADC1_IN0)，0~3.3V 映射为 **15~45 ℃**；转电位器温度就变 |
| 温度（兜底） | **固件模拟** | ADC 读不到（电位器没接）时：25 ℃ 起每秒 1 ℃ 升到 38 ℃ 再降回 |
| 心率 | **固件模拟** | 66~90 BPM，**每秒变 1 格**，约 24 s 一个来回 |
| 血氧 | 固定占位 | 有脉搏时显示 97 |
| 跌倒 | 真实 | SW3（PB1，低电平有效，20 ms 去抖） |
| 蜂鸣器 | 真实 | 跌倒时 PA12 拉低 |

屏幕第 2 行右侧的 `SIM` / `DS18` 是**数据来源标记**：
`POT` = 电位器 RV2 的 ADC 值，`SIM` = 软件模拟，`DS18` = 真的从 DS18B20 读到（当前仿真里不会出现）。

答辩时照这个说即可：**仿真环境缺少 MAX30102 / 可用的 DS18B20 模型，温度与心率由固件模拟，
跌倒、报警、显示、按键逻辑全部为真实代码路径。**

## 3. 接线（与 `SIT_sim.pdsprj` 一致）

| 外设 | 引脚 |
|---|---|
| OLED（软件 I2C） | SCL→PA5，SDA→PA6 |
| DS18B20 DQ | PA8（4.7 kΩ 上拉到 3.3 V） |
| 蜂鸣器（有源，低电平响） | PA12 |
| 心跳脉冲输入 | PB0（上拉输入） |
| 跌倒开关 SW3 | PB1（上拉输入，另一端 GND） |

## 4. 想换成真传感器怎么办

1. **换 DS18B20 模型**：在 Proteus 里换用 Pro 自带 `DS18B20` 数字温度计模型（或 `DS1621`），
   固件不需要改——上电会自动扫描时序，读通后自动从 `SIM` 切到 `DS18`。
2. **用电位器**：`RV2` 两端接 3.3 V / GND，抽头接 PA0 —— 已实现（ADC1_IN0，15~45 ℃）。
3. **心率想跟 CLOCK 联动**：把 `USER/main.c` 里的 `HR_USE_PULSE` 改成 `1`，
   心率就改用 PB0 的外部中断测周期。注意仿真步长（`Timestep per Frame`）太粗时读数会偏。
